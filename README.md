Entrega para el modulo 5 para the power análisis de datos

Hemos realizado varias consultas sobre una BBDD de una tienda ficticia de películas.
Para poder realizar las consultas, las hemos realizado bajo el programa Dbeaver.

Una vez creada la BBDD sobre la tienda de películas y poder realizar las consultas propuestas. Hemos revisado el esquema para ver las relaciones entre las tablas,
así como las columnas de cada tabla así como su tipo de variables.

Posteriormente hemos ido resolviendo y respondiendo las preguntas una a una creando una consulta lo más legible posible.

Estas consultas nos han servido para poder analizar y traer datos sobre las películas del inventario, descubriendo información sobre:

- Los actores que han interpretado algún personaje
- Las categorías de las películas 
- Los clientes y los alquileres
- Información sobre el beneficio de la tienda
- Las películas y stock disponible
